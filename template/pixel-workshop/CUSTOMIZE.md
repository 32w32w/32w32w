# 换成你自己的主页

## 用填写页修改

先下载 [`customize.html`](customize.html) 到电脑，再用浏览器打开。直接在 GitHub 文件页面查看它时，不会出现可用的填写表单。

填写页支持预览、下载正文、下载横幅、保存配置、导入配置和恢复示例。每次修改完，请重新下载需要更新的文件；它不会替你登录 GitHub，也不会自动修改已经发布的主页。

| 字段 | 填什么 | 示例 |
| --- | --- | --- |
| GitHub 用户名 `username` | 真实用户名，不带 `@`，也不是完整网址 | `your-handle`，使用前替换 |
| 昵称 `displayName` | 希望访客看到的名字 | 你的昵称 |
| 一句话 `tagline` | 简短的个人标语 | 灵感随手记，作品慢慢做。 |
| 简介 `intro` | 正在学习、制作或关注的事情 | 一小段自然的自我介绍 |
| 配色 `theme` | `purple`、`mint`、`peach` 三选一 | `purple` |
| 项目 `projects` | 最多 3 项，每项填写名称、说明和完整链接 | 自己的仓库或作品网址 |
| 便签 `notes` | 最多 3 条近期动态或交流主题 | 正在学习的内容 |

项目链接建议直接复制目标页面的 `https://` 地址。示例中的项目网址仅演示格式，模板不会替你创建这些项目。

**保存配置：** 下载 `profile.json`，下次用“导入配置”继续修改。[profile.example.json](profile.example.json) 展示了完整格式。配置与手工修改的 README 不会自动同步；改过 README 后若重新导出，记得保留自己的修改。

## 放进自己的 GitHub 仓库

将导出的 `README.md` 放在公开同名仓库的根目录，将 `banner.png` 放在根目录的 `assets` 文件夹中。图片引用使用相对路径：

```markdown
![横幅说明](assets/banner.png)
```

如果你改了图片文件名或存放位置，需要同步修改这一行。使用自己的图片时，推荐保持 **1800 × 750 像素**或相同宽高比，方便延续模板的布局。

发布前检查：

- 把 `your-handle`、`你的昵称`、`这里是你的简介`和所有示例项目换成自己的内容。
- 点击每个项目链接，确认地址属于你想展示的项目。
- 在仓库中打开 README，确认横幅没有变成破图。
- 确认仓库公开、仓库名与用户名一致，且 README 位于根目录。

不需要把填写页、配置文件或整个模板目录上传到你的个人主页仓库。它们是制作工具；主页展示只需要正文和图片。

## 直接编辑 Markdown

[`profile/README.md`](profile/README.md) 是可复制的正文示例。你可以删掉不用的项目，修改“工作台便签”，或添加联系地址。GitHub 会按照自己的 Markdown 样式显示正文。

模板中的横幅是一张 PNG。直接修改 README 里的昵称或标语，不会改变图片内的文字；需要同步修改图片时，请在填写页中更新并重新下载横幅。

## 常见情况

**打开 HTML 只看到代码：** 先用 GitHub 的“Download raw file”保存 HTML 到电脑，再用浏览器打开下载的文件。

**仓库里能看到正文，个人主页没有：** 检查是否为公开同名仓库，以及 README 是否放在根目录。[查看 GitHub 的显示条件](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme)

**文字太长：** 优先缩短昵称与标语，把详细介绍留在正文。导出前查看预览，尤其留意窄屏下的阅读效果。
